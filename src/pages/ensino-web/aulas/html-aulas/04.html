Slide 1 — Introdução à formatação

O HTML oferece tags nativas para formatar texto sem precisar de CSS. Elas permitem destacar informações importantes e melhorar a leitura, sem alterar a estrutura da página.

Slide 2 — Negrito e itálico

Use <strong> para negrito e ênfase importante, e <em> para itálico, indicando destaque ou entonação no texto. Essas tags também contribuem para a acessibilidade.

Slide 3 — Sublinhado e marcação

Para sublinhar, use <u>, e para destacar trechos específicos, utilize <mark>. Essas tags ajudam a enfatizar informações sem alterar o layout geral.

Slide 4 — Citações

Para incluir citações longas, use <blockquote>, e para citações curtas dentro de um texto, use <q>. Elas indicam fontes e melhoram a credibilidade do conteúdo.

Slide 5 — Código em linha e blocos de código

Use <code> para trechos de código em linha e <pre> para blocos de código preservando espaços e quebras. Isso facilita a leitura e compreensão de exemplos técnicos.

Slide 6 — Reflexão

Entender as tags de formatação nativa permite destacar informações importantes sem depender de CSS. Saber quando usar cada tag ajuda a criar conteúdo claro e acessível. Próxima Aula — Listas e tabelas
