Introdução ao HTML

Nesta leitura você vai entender o que é HTML, para que ele serve e como montar a estrutura mínima de uma página web. Ao final você será capaz de criar um arquivo index.html, abrir no navegador e ver o seu primeiro site simples.

O que é HTML?

HTML (HyperText Markup Language) é uma linguagem de marcação: ela descreve a estrutura do conteúdo de uma página, títulos, parágrafos, listas, imagens e links. Diferente de linguagens de programação, o HTML não “computar” lógica; ele organiza o que será exibido pelo navegador. Pense no HTML como o esqueleto e o conteúdo do seu site.

Explicação do código (Parte 1)

<!DOCTYPE html> — aviso para o navegador de que este documento usa HTML5. É uma linha técnica importante no começo.

<html>...</html> — envolve todo o conteúdo da página; é a tag raiz do documento.

<head>...</head> — contém informações sobre a página que não aparecem diretamente no corpo (como o título que aparece na aba do navegador). Aqui também se colocam links para estilos e metadados.

See the Pen Estrutura básica de uma página by WandersonMateus (@WandersonMateus) on CodePen.

Explicação do código (Parte 2)

<title> — o texto dentro desta tag aparece na aba do navegador; é importante para identificação da página.

<body>...</body> — tudo que estiver aqui será exibido na tela: textos, imagens, links, botões.

<h1>...</h1> — título principal da página (ex.: cabeçalho). Existem também <h2>, <h3>... para subtítulos.

<p>...</p> — parágrafo; usado para blocos de texto.

Antes de escrever o código, é necessário ter um editor de código instalado no computador. Nesta etapa, utilizaremos o Visual Studio Code (VS Code), um dos editores mais usados por desenvolvedores web.
