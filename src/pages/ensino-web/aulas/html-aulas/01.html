Slide 1 — O que é HTML

HTML (HyperText Markup Language) é a linguagem de marcação utilizada para criar páginas web. Ele organiza o conteúdo em blocos chamados tags, que formam elementos que os navegadores interpretam e exibem para o usuário.

Slide 2 — Estrutura básica de um documento

Um documento HTML começa com a declaração <!DOCTYPE html>, seguida pelas tags <html>, <head> e <body>. O <head> contém informações da página, como título e links para estilos, enquanto o <body> abriga o conteúdo visível.

Slide 3 — Títulos

O HTML possui seis níveis de títulos, de <h1> a <h6>. O <h1> representa o título principal da página, e os demais títulos organizam seções e subseções. Usar títulos corretamente melhora a hierarquia e a compreensão do conteúdo.

Slide 4 — Parágrafos

A tag <p> é usada para criar parágrafos, organizando o texto em blocos legíveis. Cada parágrafo representa uma ideia ou conjunto de informações, garantindo uma leitura mais clara e agradável para o usuário.

Slide 5 — Combinando títulos e parágrafos

Uma página bem estruturada combina títulos e parágrafos para criar hierarquia e organizar o conteúdo. O título apresenta o tema, enquanto os parágrafos detalham as informações, tornando a leitura clara e objetiva.

Slide 6 — Reflexão
