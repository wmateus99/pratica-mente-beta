Slide 1 — Introdução ao Box Model

O Box Model é o conceito central do CSS para definir como cada elemento ocupa espaço na página. Cada elemento é composto por conteúdo, padding (preenchimento interno), border (borda) e margin (espaço externo).

Slide 2 — Padding

O padding define o espaço interno entre o conteúdo do elemento e sua borda. É útil para afastar o conteúdo das bordas e melhorar a leitura e estética do layout.

Slide 3 — Border e Margin

A border é a borda do elemento, enquanto a margin é o espaço externo que separa o elemento dos demais na página. Entender como combinar padding, border e margin é essencial para criar layouts consistentes e harmoniosos.

Slide 4 — Reflexão

Dominar o Box Model permite controlar com precisão o espaço, o alinhamento e o tamanho dos elementos. Isso é fundamental para criar layouts limpos e responsivos. Próxima Aula — Tipografia e fontes
