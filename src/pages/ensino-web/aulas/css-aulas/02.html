Slide 1 — Seletores de tag, classe e id

Os seletores são a base do CSS. Seletores de tag aplicam estilos a todos os elementos de um tipo (ex: p, h1). Seletores de classe (.classe) estilizam elementos específicos com a mesma classe. Seletores de id (#id) aplicam estilos a um único elemento único.

Slide 2 — Cores no CSS

O CSS permite definir cores para texto, fundo, bordas e outros elementos. É possível usar nomes de cores (red, blue), códigos hexadecimais (#FF0000), RGB (rgb(255,0,0)) ou HSL (hsl(0,100%,50%)).

Slide 3 — Seletores avançados

Existem seletores mais específicos como: combinadores (div p), pseudo-classes (:hover, :first-child) e pseudo-elementos (::before, ::after). Eles permitem estilizar elementos com base em posição, interação ou conteúdo.

Slide 4 — Reflexão

Compreender seletores e cores é essencial para controlar a aparência de um site. Saber escolher o seletor correto e aplicar cores de forma harmoniosa torna o layout mais consistente e agradável. Próxima Aula — Box Model e espaçamento
