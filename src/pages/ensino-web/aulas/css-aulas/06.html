Slide 1 — O que é o Box Model

No CSS, cada elemento é uma caixa composta por conteúdo, padding, border e margin. Entender essa estrutura permite controlar tamanhos, espaçamentos e alinhamentos de forma precisa.

Slide 2 — Padding

O padding é o espaço interno entre o conteúdo e a borda da caixa. Ele aumenta a área interna sem afetar o tamanho total do elemento, proporcionando respiro ao conteúdo.

Slide 3 — Border

As bordas (border) contornam o conteúdo e o padding da caixa. Podemos definir largura, estilo e cor. Bordas podem ser usadas para destacar elementos ou criar separações visuais.

Slide 4 — Margin

O margin define o espaço externo entre uma caixa e outros elementos. É útil para separar seções, alinhar elementos e manter o layout limpo e organizado.

Slide 5 — Reflexão
