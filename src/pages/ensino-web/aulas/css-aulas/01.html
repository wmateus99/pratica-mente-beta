Slide 1 — O que é CSS

CSS (Cascading Style Sheets) é a linguagem usada para estilizar páginas HTML. Ele permite controlar cores, fontes, espaçamentos, layouts e efeitos visuais, separando o conteúdo da apresentação.

Slide 2 — Formas de aplicar CSS

Existem três maneiras principais de aplicar CSS: inline, diretamente no elemento HTML; interno, dentro da tag <style> no <head>; e externo, usando arquivos .css vinculados com <link>.

Slide 3 — Seletores básicos

Os seletores permitem escolher quais elementos HTML serão estilizados. Os mais comuns são por tag (ex: p), classe (ex: .card) e id (ex: #header).

Slide 4 — Reflexão

CSS é essencial para transformar páginas simples em experiências visuais atraentes e funcionais. Aprender a usar CSS corretamente é o primeiro passo para criar sites modernos. Próxima Aula — Seletores e cores
