  1. Acesse o site do editor de códigos Visual Studio Code.
  2. Baixe e instale o programa no computador.
  3. Após a instalação, abra o programa e faça as seguintes configurações:
    • Mudar Idioma: Use o atalho CTRL + SHIFT + P, na caixa de pesquisa que surgir, digite “Display Language” e aperte “Enter”, então basta escolher o idioma português.
    • Instalar Extensão: Na barra de menus ao lado, procure a opção “Extensões” e instale a extensão “Live Server”.
  4. Agora que o programa está configurado, crie uma pasta na “Área de Trabalho” com o nome “Login”.
  5. Arraste a pasta para dentro do editor de código.
  6. Crie a seguinte estrutura de pastas e arquivos:

  10. Explicação das tags usadas no código:
    • <div>: cria divisões ou blocos na página para organizar o layout.
    • class="...": identifica o bloco com um nome para ser estilizado no CSS.
    • <img>: insere uma imagem, no caso o logo da escola.
    • alt="...": texto alternativo exibido caso a imagem não carregue.
    • <h2>: título de seção, aqui usado para a mensagem “Digite seu usuário e senha”.
    • <form>: define um formulário que pode conter campos e botões.
    • <input type="text">: campo de texto para digitar o usuário.
    • <input type="password">: campo para senha, oculta os caracteres digitados.
    • placeholder="...": texto exibido dentro do campo até o usuário digitar algo.
    • <button>: cria um botão, neste caso com o texto “Acessar”.
  11. A parte do HTML já está pronta, agora clique com o botão direito do mouse sobre o código e escolha a opção “Open With Live Server”.
